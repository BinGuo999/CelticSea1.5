These internal NEMO tools in NEMO_VER/tools are used for NEMO input building or diagnosis and other additionalfunction. Here we build four a domain, prepare interpolation weights, and combine output split across MPI ranks. Here we provide the four Compile them after building NEMO, which installs the source tree and the Cirrus architecture file.

Compile the tools

Run the script from Scripts/.

. ./5.make_tools.sh

The script loads the same GNU, HDF5 and NetCDF modules as the NEMO build. It makes two sets of source changes before compiling.

  1. It copies dom_oce.f90, domain.f90 and domzgr.f90 from CS1.5_NEMO_support/DOMAINcfg_src/ into $TDIR/DOMAINcfg/src/. These files add the Celtic Sea wetting and drying changes, including writing ht_wd and rn_wd_ref_depth to domain_cfg.nc.

  2. It applies the five WEIGHTS patches in CS1.5_NEMO_support/tool_patch_files/.

Find the executables

maketools builds each tool with $HPC_TARG from 1.make_path.sh. Look for the results under $TDIR ($NEMO/tools).

Tool Purpose Executables, relative to $TDIR
NESTING Prepare nested coordinates, bathymetry and other inputs NESTING/BLD/bin/agrif_*.exe
REBUILD_NEMO Combine files written separately by MPI ranks REBUILD_NEMO/BLD/bin/rebuild_nemo.exe
WEIGHTS Prepare horizontal interpolation weights and remap fields for surface forcing WEIGHTS/BLD/bin/ contains scrip.exe, scripgrid.exe, scripinterp.exe and scripshape.exe
DOMAINcfg Generate domain_cfg.nc from grid and bathymetry inputs DOMAINcfg/BLD/bin/make_domain_cfg.exe

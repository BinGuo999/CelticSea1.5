Once you have compiled XIOS and NEMO, you can run the CelticSea1.5 test case. This guide describes the inputs needed for a fully forced run and where to download the model grid and sample forcing files. You can run the test now using these files, or work through the input generation steps first and return to this section later. You can also switch individual forcings on or off to build up the model setup gradually and check that each input works as expected.

The following sections provide step-by-step instructions and scripts for generating the domain configuration file (domain_cfg.nc) and the required forcing inputs.

Prepare the run directory

In Scripts/1.make_path.sh, set FORCING_DIR to the path of the downloaded CelticSea1.5_input_1993. The bundle contains domain_cfg.nc at its root, and input data in IC/, OBC/, SBC/, River/ and TIDES/.

Prepare the test run from Scripts/.

. ./1.make_path.sh
. ./6.make_test_run.sh
cd $EXP

The script copies the namelists, XIOS XML files and runnemo.slurm from RUN_DIRECTORIES/EXP_test_1993/ to $EXP. The default destination is $WDIR/RUN_DIRECTORY/CS1.5_1993_TEST. Use a fresh experiment directory for a new run. Step 6 copies over existing template files and stops if one of its symbolic links already exists.

Path in the run directory Input
domain_cfg.nc Celtic Sea grid and bathymetry information
IC/ Temperature and salinity information on 1 January 1993
OBC/ Monthly open boundary files for 1993. The job also reads coordinates.bdy.nc for boundary grid information.
SBC/ 1993 ERA5 forcing and both atmospheric interpolation weights. Keep the weights inside SBC/, where NEMO reads them.
river/ 1993 GloFAS runoff
TIDES/ FES2014 tidal boundary files
nemo.exe, xios_server.exe Links to the executables under $CONFIG_DIR/BLD/bin/ and $XIOS_DIR/bin/, respectively

Edit the namelist

A namelist is a text file that set up the numerical options in NEMO model. namelist_ref supplies the default settings, and namelist_cfg supplies the settings for this specific experiment. In this configuration, namelist_cfg is regenerated from namelist.template for each month, allowing the simulation to run in monthly segments, with the output archived separately for each month. So, do not edit namelist_cfg, edit namelist.template.

Some key namelist settings: - cn_domcfg = "./domain_cfg.nc" selects the Celtic Sea grid file. - rn_rdt = 80. sets an 80-second timestep. - ln_tsd_init = __INITS__ controls whether NEMO reads the initial temperature and salinity. The Slurm script sets it to .true. for the first month and .false. for restart months. - ln_blk = .true. enables the bulk formula for ERA5 surface forcing. - ln_rnf = .true. enables river runoff. - ln_bdy = .true. enables open boundary conditions. - ln_tide = .true. enables tidal forcing.

Edit the Slurm script

Modify runscript.slurm for your HPC environment (account details, queue, walltime, and core count).

In the CelticSea1.5 hindcast, simulating January through December 1997 took about 1 hour and 50 minutes of wall-clock time on four Cirrus nodes (1 hour, 48 minutes and 11 seconds in Slurm job 630493).

The variables iy1 and iy2 set the first and last simulation years. For the supplied 1993 run, ms=1 and end_month=12 select January through December, and nit0=1 starts at the first timestep. The first month reads the initial conditions. Each later month reads the restart from the previous month. The default tpd=1080 matches the 80-second timestep in the namelist. If you change rn_rdt, remember also update tpd to match the number of timesteps per day.

Submit the experiment on Cirrus

sbatch runnemo.slurm
squeue -u your_user_name

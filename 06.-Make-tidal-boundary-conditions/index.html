Use pyBDY to interpolate FES2014 tidal harmonics onto the Celtic Sea 1.5 km open boundary. The September 2026 run in CELTIC8_GEE_SF12_cutout used the 426 × 312 GEG_SF12 domain from 05. Build domain configuration file. It produced amplitudes and phases for 24 tidal constituents and the boundary coordinates used to locate them on the NEMO grid.

The 1993 test run already uses these harmonics from the forcing bundle. Follow this page to regenerate them.

1. Install pyBDY

From a checkout of pyBDY, create the Conda environment and install the package. The environment file specifies Python 3.9. The NcML reader also needs Java. pyBDY repository

conda env create -n pybdy -f environment.yml
conda activate pybdy
python -m pip install -e .
pybdy -h

2. Prepare the input files

Set ARCHIVED_RUN to the path of your copy of CELTIC8_GEE_SF12_cutout. Set DOMAIN_INPUTS to the directory containing the matching domain_cfg.nc and bathy_meter.nc, such as the backup_260921_GEG_SF12_cutout domain archive. The original links in the pyBDY archive point to ARCHER2 /work paths. Create fresh links to the Cirrus copies.

From the Celtic Sea checkout's Scripts/ directory, load the paths and prepare a working directory.

source ./1.make_path.sh

ARCHIVED_RUN=/path/to/CELTIC8_GEE_SF12_cutout
DOMAIN_INPUTS=/path/to/backup_260921_GEG_SF12_cutout

mkdir -p "$WDIR/BUILD_CFG/OPEN_BOUNDARIES/GEG_SF12_cutout"
cd "$WDIR/BUILD_CFG/OPEN_BOUNDARIES/GEG_SF12_cutout"

cp "$ARCHIVED_RUN/namelist_AMM7CELTIC.bdy" .
cp "$ARCHIVED_RUN/grid_name_map_sco.json" .
ln -s "$ARCHIVED_RUN/AMM7_domain_cfg_sub.nc" .
ln -s "$ARCHIVED_RUN/mesh_mask_from_AMM7_domain_cfg_sub.nc" .
ln -s "$ARCHIVED_RUN/bdy_mask.nc" .
ln -s "$DOMAIN_INPUTS/domain_cfg.nc" .
ln -s "$DOMAIN_INPUTS/bathy_meter.nc" .
Input Purpose
AMM7_domain_cfg_sub.nc and mesh_mask_from_AMM7_domain_cfg_sub.nc AMM7 parent grid and wet-cell mask
domain_cfg.nc and bathy_meter.nc Celtic Sea target grid and September bathymetry
bdy_mask.nc Celtic Sea open-boundary mask. Cells marked -1 are outside the open boundary, 1 marks the active domain, and 0 marks land or closed areas.
grid_name_map_sco.json NetCDF variable names for the source and target grids, both configured as sco

Keep ln_mask_file = .true. to read the saved mask and ln_coords_file = .true. to write coordinates.bdy.nc. The mask, together with nn_rimwidth = 9, defines the boundary points and their ordering.

3. Set the data paths in the namelist

Edit these two entries in the copied namelist_AMM7CELTIC.bdy.

sn_src_dir  = '/path/to/pyBDY/inputs/src_data_local.ncml'
sn_tide_fes = '/path/to/FES2014/'
  • sn_src_dir points to a readable NcML file. pyBDY opens the source reader before extracting tides. The September run used src_data_local.ncml under the archived pyBDY inputs/ directory. Keep that file beside its benchmark/data/ folder so its relative paths resolve.
  • sn_tide_fes points to your Cirrus copy of the FES2014 data directory. The archive links to the old ARCHER2 copy. Use the extrapolated elevation and both current components in ocean_tide_extrapolated/, eastward_velocity/, and northward_velocity/. Each directory should contain the constituent files, for example m2.nc. AVISO FES data access

Keep ln_tide = .true., sn_tide_model = 'FES2014', and ln_trans = .true.. The archived setup disables the time-varying barotropic, baroclinic, tracer, and ice outputs. The dates in the namelist do not limit the use of the tidal harmonics to those years.

4. Run pyBDY on Cirrus

Save the following as submitpynemo.slurm in the working directory. Set the project account and the path to your Conda installation on a filesystem accessible to compute nodes. The job starts one pyBDY process. It requests 25 cores to allow roughly the same memory as the original 64 GB ARCHER2 request on a standard Cirrus node. Cirrus resource limits

#!/bin/bash
#SBATCH --job-name=pybdy_tide
#SBATCH --account=YOUR_PROJECT
#SBATCH --partition=standard
#SBATCH --qos=standard
#SBATCH --time=02:00:00
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=25

set -e
cd "$SLURM_SUBMIT_DIR"

source /path/to/miniconda3/etc/profile.d/conda.sh
conda activate pybdy
export JAVA_HOME=/usr/lib/jvm/jre-11
export OMP_NUM_THREADS=1

mkdir -p output_20260922
pybdy -s namelist_AMM7CELTIC.bdy

Submit from the directory containing the namelist.

sbatch submitpynemo.slurm

5. Check the output

The September namelist writes to output_20260922/. Expect coordinates.bdy.nc and 72 tidal NetCDF files, one per grid (T, U and V) for each of the 24 constituents. For example, the M2 files are named CELTIC_bdytide_FES2014_M2_grid_T.nc and similarly for U and V.

ls -lh output_20260922/coordinates.bdy.nc
find output_20260922 -maxdepth 1 -name 'CELTIC_bdytide_FES2014_*_grid_[TUV].nc' | wc -l

The 1993 test-run script links files from the forcing bundle's TIDES/ directory and uses OBC/coordinates.bdy.nc at the run-directory root. The NEMO namelist reads the prefix ./TIDES/CELTIC_bdytide_FES2014_. When substituting regenerated harmonics, check that their boundary points and ordering still match the coordinates used by the monthly AMM7 boundary files. The archived tidal coordinates and the forcing bundle's boundary coordinates have identical NetCDF variable values.

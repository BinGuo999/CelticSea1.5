The Celtic Sea grid is a 426 × 312 cutout of the AMM15 GEG_SF12 grid. It uses Siddorn and Furner (2012) vertical stretching, with 31 levels and up to 30 wet levels, features with wetting and drying function.

1. Extract the coordinates and bathymetry

The DOMAINcfg tool needs two inputs to build domain_cfg.nc. The coordinates file provides the horizontal grid, and the bathymetry file provides the water depth. For the Celtic Sea configuration, both are extracted from the AMM15 domain file, GEG_SF12.nc.

Place GEG_SF12.nc or a link to it in $WDIR/BUILD_CFG/DOMAIN. From the checkout's Scripts/ directory, run the following in a Python environment with xarray and a NetCDF backend.

. ./1.make_path.sh
cd "$DOMAIN"
python "$gituhb_download/BUILD_CFG/DOMAIN/cutout_bathy_subset.py"
python "$gituhb_download/BUILD_CFG/DOMAIN/cutout_coordinates_subset.py"

Both scripts extract the same 426 × 312 window using zero-based indices x = 500–925 and y = 244–555, inclusive. The bathymetry script marks land and missing depths with -9999, which is in line with WAD compatible bathymetry. The scripts write CelticS_coordinates.nc and CelticS_bathy_meter.nc.

For more information on preparing coordinate and bathymetry files, see the SEVERN-SWOT guide to building a domain configuration file.

2. Generate and check domain_cfg.nc

From the checkout's Scripts/ directory, load the paths and prepare the inputs in $TDIR/DOMAINcfg.

. ./1.make_path.sh
cd $TDIR/DOMAINcfg

cp $gituhb_download/BUILD_CFG/DOMAIN/namelist_cfg .
cp $gituhb_download/BUILD_CFG/DOMAIN/job_create_domain.slurm .
ln -s BLD/bin/make_domain_cfg.exe .
ln -s $DOMAIN/CelticS_coordinates.nc coordinates.nc
ln -s $DOMAIN/CelticS_bathy_meter.nc bathy_meter.nc

Use the namelist_ref and XML files already in the tool directory. The supplied namelist_cfg reads bathy_meter.nc (nn_bathy = 1), selects Siddorn and Furner stretching (ln_s_sf12 = .true., rn_hc = 50 m), sets the wetting and drying reference depth to 0 m, and writes mesh_mask.nc (nn_msh = 1).

sbatch job_create_domain.slurm

Once the job finishes, check the generated domain_cfg.nc in this $TDIR/DOMAINcfg.

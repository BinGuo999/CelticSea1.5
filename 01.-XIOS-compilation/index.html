These instructions build the Celtic Sea 1.5 km ocean configuration on Cirrus using XIOS3 and NEMO 4.0.4 with GNU and MPICH. Build XIOS first. It supplies the library NEMO links against and the server executable launched alongside the model.

Set up the paths and directories

Start with a checkout of CelticSea1.5

 git clone https://github.com/BinGuo999/CelticSea1.5.git
 cd CelticSea1.5

The core building scripts are in /SCRIPTS, where containing six numbered shell scripts that navigate the whole process of NEMO model building.

In principle, the only file you need to editor is Scripts/1.make_path.sh(but in many cases minor issues arise and you need to make your relavent adaption). Open the file and check the following settings:

Setting What to enter
gituhb_download Absolute path to the CelticSea1.5 checkout.
WDIR A writable directory on your directory, where everything happened.
CONFIG NEMO configuration name (adapt it for your own model).

Change NEMO_VER=NEMO_4.0.4 and HPC_TARG=cirrus-gnu-mpich for your own build. FORCING_DIRis a directory that containing the domain and forcing files for a test run.

cd Scripts
. ./1.make_path.sh
. ./2.make_directories.sh

The first script, 1.make_path.sh, sets and prints the paths. The 2.make_directories.sh, uses those paths to create the build and run folders.

Build XIOS3 on Cirrus

The XIOS build uses the shared files at /epccfs/n01/shared/xios3. If you do not have the access to it, then you need to download the xios3 source code or use other version of xios like 2.5.

Run the build from Scripts/.

. ./3.make_xios.sh

The script loads PrgEnv-gnu and the parallel HDF5 and NetCDF modules. Use the same compiler and library environment for the NEMO build.

The script copies XIOS to $XIOS_DIR and adapts the ARCHER2 settings for Cirrus.

  • .fcm sets the compilers and build flags.
  • .path tells XIOS where to find NetCDF and HDF5.
  • .env contains only a comment because the script already loads the Cirrus modules.
  • The script removes -lmpichf90 because the Fortran compiler wrapper (ftn) already adds the MPI library.

The script then runs this command inside $XIOS_DIR.

./make_xios --prod --arch X86_CIRRUS-Gnu --netcdf_lib netcdf4_par --job 16 --full

Check the build

The script checks that the server is executable.

echo "Executable is $XIOS_DIR/bin/xios_server.exe"

Continue with 02. Compile NEMO once both files are present.
